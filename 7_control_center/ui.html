Search extraction

Search a platform for your phrases and record every video it returns, with its rank, likes and views. The result goes to the dashboard as search-rank links.

What to search

One phrase per line. Each is searched separately and the results are merged.

When it finishes

The upload runs as its own job, so you can watch it, stop it, or re-run it alone.

Replace drops rank links that this scrape no longer returns, which is what you want for a full sweep of a keyword. Append is for one keyword out of several uploaded separately. Neither touches links that have no search rank, and neither touches another genre: a Website builder search replaces only the Website builder links of that platform, never the Humanizer ones.

Each platform uploads its own file, named by the scraper that wrote it — not “the newest CSV”, which with several searches running at once belongs to whichever finished last.

Platforms are searched one after another: they share a Chrome profile and Chromium allows one window per profile. The queue is on the Jobs page. Searches start straight away — there is no log-in-and-press-Enter step. The Chrome profile keeps your logins; if Instagram finds itself signed out, it waits in the browser window and starts by itself once you log in.

YouTube counts as two runs when both tabs are wanted. Its results page mixes Shorts with long videos, and the scraper only clicks a filter tab when it is told which one — so “Both” runs the Shorts tab first and the Videos tab after, each writing and uploading its own file.

Instagram channels

The dashboard turns its Instagram links into a ranked channel list — the same order the Links-to-verify extract page shows — and this visits the best of them and collects the posts newer than what we already hold. Everything found is staged on Links to verify for you to review and merge.

How much to scan

Channels come from the dashboard's own ranking, Instagram only, best first — so a smaller number is the strongest ones, not an arbitrary slice. With a genre picked, the ranking is filtered to that genre first, so the number is that many of its channels rather than that many overall.

Nothing here reaches a user. Staged links still have to be reviewed and merged on the Links-to-verify page, exactly as an uploaded CSV does.

The browser is always on screen for this one — Instagram's profile page is a JavaScript shell, so the posts only exist once something has run the page. There is no headless mode to turn on.

Zefoy liker

Give hearts to our comments through Zefoy or Freer, so the comment a visitor reads first is ours. No account of ours is used — the free service does the liking. For our own accounts, see Account liker. Runs alongside everything else on this page.

The phone

Hearts can be given from the phone's own Chrome instead of a browser here — its session, its IP, its captcha. Attach it first; the run refuses to start without it.

checking…

Connecting runs adb connect (if an address is given), then adb reconnect and adb forward, and restarts Chrome on the phone if its debugging socket is missing — Chrome opens that socket once at startup, so a Chrome that ran through a disconnect has none. A restarted Chrome has no Zefoy session, so expect a captcha; the AI solves it.

Where to run

Tick both and one press starts two runs — the PC's browser and the phone's — working the same list.

Service and links

Target

What “done” means for a video.

Two limits, and the comment is worked to sit between them: never thinner than the floor (a share of the video's own likes, worked even when it already leads) and never thicker than the ceiling, HEART_THRESHOLD — a comment carrying more hearts than the video it sits under is a comment nobody believes. A tie is the one exception to the ceiling: level with the best stranger, it sends one batch and moves on.

Pace, place and memory

On the phone, keep Chrome in front and the screen unlocked — a tab nobody is looking at is not drawn, and the captcha image never arrives.

Two runs, two ways. Give them different tags and they are independent: separate records, each working the whole list. Give them the same tag and tick Share and they are one piece of work: a link claimed by one is skipped by the other, so neither repeats it — and if the phone drops, the PC goes back for whatever it was holding and finishes the list alone.

Account liker

Hearts our comments from our own TikTok accounts — the sessions login.py saved — rather than through a free service. Slower and finite, because it spends our accounts' own standing, but it does not queue behind anybody's quota and there is no captcha to solve.

Which links

The same pool the Zefoy liker works from, and the same clustering — the dashboard assigns the clusters, this only picks which ones to take.

What to like, and as whom

A video costs one page load, and every matching comment on it is liked while the page is open.

Every like is written to done.csv as it happens and rows already there are skipped, so a re-run carries on rather than repeating.

Sign in first. This uses a session login.py saved; a profile that has never been logged in has nothing to like with.

Jobs

Everything this window has started. They run independently — stopping one leaves the others alone. The scraper and the harvester share one Chrome profile, so those queue: Chromium allows a single window per profile, and a second one would be refused on the spot.
